# e-Yantra MSIT Design System

## Product Context
The official website for the e-Yantra MSIT society.
Theme: Robotics, engineering lab, experimentation, and student innovation.
Core Vibe: Technical, editorial, premium but grounded. Clean mechanical feel.

## Anti-Patterns (AVOID THESE)
- NO generic AI-generated SaaS looks
- NO purple/blue startup gradients
- NO cyberpunk/neon styling
- NO gaming/crypto styling
- NO excessive glassmorphism
- NO overdecorated UI

## Visual Language
- **Typography:** Strong, technical, editorial. Use modern clean sans-serif (e.g., Inter, Roboto, or SF Pro) for body/headings, and monospaced fonts (e.g., JetBrains Mono, Fira Code) for technical details and accents.
- **Spacing:** Precise, structured, grid-based.
- **Motifs:** Subtle grid, circuit, or engineering motifs.
- **Shadows:** Minimal. Flat or barely-there borders instead of heavy drop shadows.

## Color Palette
- **Background:** `#0B0D10` (Very dark, near black)
- **Surface:** `#15181C` (Dark gray for cards/sections)
- **Primary Text:** `#F3F2EE` (Off-white for readability)
- **Secondary Text:** `#A6AAAE` (Muted gray for supplementary text)
- **Accent Color:** `#D83A32` (Red - use sparingly for primary CTA, active nav, section markers, hover accents, important technical details)
- **Borders/Lines:** `#292D32` (Subtle structural lines)

## Layout Structure
- **Navbar:** Sticky, subtle compact-on-scroll behavior.
- **Hero:** Immersive, clean, space for 3D robotics visual interaction (light parallax, restrained scroll response).
- **Cards (Projects, Events, Team):** Avoid flat walls of identical cards. Differentiate structures slightly while maintaining grid alignment. Use subtle borders (`#292D32`) and surface backgrounds (`#15181C`).

## Components
- **Buttons (Primary CTA):** Red accent (`#D83A32`), crisp edges, minimal border-radius.
- **Buttons (Secondary):** Outline using `#292D32`, text `#F3F2EE`, hover state uses subtle surface change or red accent.
- **Sections:** Delineated by subtle borders or slight background color changes (between `#0B0D10` and `#15181C`).
